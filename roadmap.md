# Roadmap

- [x] Permitir abrir qualquer lançamento para editar todos os campos.
- [x] Permitir excluir um lançamento com confirmação.
- [x] Interpretar comandos simples na SOLE AI para receitas e despesas.
- [x] Confirmar os dados inferidos antes de criar o lançamento real.
- [x] Usar o usuário atual como pagador/recebedor padrão.
- [x] Validar os fluxos no desktop e no celular.
- [x] Aceitar comandos de voz iniciados diretamente por “Sole gastei” ou “Sole recebi”.
- [x] Encerrar a gravação automaticamente após o fim da fala.
- [x] Gerar imediatamente a prévia editável do lançamento interpretado, mantendo a confirmação antes de salvar.
- [x] Corrigir a detecção de fala e o reconhecimento do gatilho de voz em diferentes microfones.
- [x] Editar e excluir projetos com confirmação, preservando seus lançamentos.
- [x] Exibir o nome do projeto em cada lançamento vinculado.
- [x] Abrir detalhes de cada projeto com indicadores e todos os seus movimentos.
- [x] Validar criação, edição, detalhes e exclusão de projetos.
- [ ] Adicionar manifesto e ícones SOLE3 para instalação.
- [ ] Adicionar modo offline seguro e proteção da prévia.
- [ ] Validar manifesto, ícones e comportamento offline.
